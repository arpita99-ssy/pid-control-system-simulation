# pid-control-system-simulation
Python simulation of a PID-controlled system with animation and error plots
The PID controller computes control force as:
u(t) = Kp·e(t) + Kd·de/dt + Ki·∫e(t)dt

where e(t) is the horizontal position error between the target and the platform.
# Water Tank Level Control – PID Simulation

This project is an academic simulation of a water tank level control system.
The original model was developed by Mark Misin Engineering and has been
modified and extended for learning purposes.
